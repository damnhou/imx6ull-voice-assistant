# 测试与 94% 指标验证计划

“识别准确率达到 94%”不能仅由代码或热词文件证明。本项目把它定义为待板端测试的数据指标，避免在简历或 README 中写成未经验证的结论。

## 指标定义

针对 LED 指令场景，建议同时记录：

- 关键词准确率：正确识别的目标关键词数 / 关键词总数。
- 指令成功率：执行了正确硬件动作的指令数 / 有效指令总数。
- 字错误率（CER）：编辑距离 / 参考文本总字数。
- 端到端延迟：停止说话到 LED 状态改变的 P50/P95。

## 数据集

至少 10 名说话人，每人 30 条指令；覆盖男女声、正常/远场距离、安静与风扇噪声。保留固定测试集，不用它反复调词表。建议指令包括：

- 打开/开启/点亮开发板指示灯。
- 关闭/关掉/熄灭板载 LED。
- 切换/翻转指示灯。
- 相近发音和无关语句（负样本）。

## 对照实验

1. 不发布热词的基线。
2. 在讯飞控制台上传并发布 `config/userwords.txt`。
3. 保持设备、音量、网络和测试集一致，再跑一次。
4. 输出原始识别文本、期望动作、实际动作、SID、延迟和环境标签。
5. 用 Wilson 置信区间报告成功率；样本数不足时不要写“稳定达到”。

## 当前可执行的自动测试

`tests/` 覆盖鉴权 URL 结构、动态修正结果替换、LED 指令解析。它们不替代 TLS、麦克风、云服务和 sysfs 的集成测试。
