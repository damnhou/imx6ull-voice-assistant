# 求职项目表述（按当前完成度）

## 项目名

VoiceEdge：基于 i.MX6ULL 与 Qt 的流式语音控制终端

## 当前可据实使用的描述

- 面向 NXP i.MX6ULL/Cortex-A7 设计 Qt 5 嵌入式应用，完成 800×480 触控交互界面、应用状态机及音频/云服务/业务/BSP 分层。
- 基于讯飞语音听写 WebAPI 实现 HMAC-SHA256 鉴权、WebSocket 音频分帧、流式结果解析和 `wpgs` 动态修正合并，密钥通过环境变量或外部配置注入。
- 实现 16 kHz、16 bit、单声道 PCM 采集与音量反馈，并通过 `ILedDevice` 抽象和 Linux sysfs 联动板载 LED；支持 PC/板端演示模式切换。
- 建立用户词表、命令意图解析与可复现实验方案；识别准确率和端到端时延等待板端数据集实测后量化。

## 完成实测后再替换的描述模板

> 基于固定测试集完成热词优化前后对照实验，关键词准确率由 **X%** 提升至 **Y%**，LED 指令成功率达到 **Z%**，端到端 P95 延迟为 **N ms**。

不要在没有原始测试记录时填写 94%。面试中能解释指标口径、样本规模和失败案例，比单独给一个漂亮数字更可信。
